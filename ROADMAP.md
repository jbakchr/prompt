# prompt Roadmap

This roadmap is intentionally simple.

The goal is not to build the ultimate prompt engineering tool.

The goal is to build a useful CLI that helps create, improve, and review prompts with as little friction as possible.

---

# Vision

Create a CLI that helps users:

1. Create new prompts from guided questions
2. Improve existing prompts
3. Review prompts and receive actionable feedback

The CLI should act as a practical prompt assistant, not a prompt engineering course.

---

# Phase 1: Foundation

## Goal

Create a minimal but useful CLI that can generate prompts through a guided question flow.

## Features

### create

```bash
prompt create
```

Ask the user:

- What is the goal?
- Who is the intended audience?
- Should the AI take on a role?
- Any specific instructions?
- Desired output format?

Send answers to an AI model.

Generate a prompt draft.

Display the generated prompt.

### Save Prompt

Allow prompts to be saved to disk.

Example:

```bash
prompt create --output summarize.md
```

or prompt the user for a filename.

## Success Criteria

- User can create a prompt from the terminal
- Prompt is generated by AI
- Prompt can be saved as a file
- Manual testing feels useful

---

# Phase 2: Prompt Improvement

## Goal

Allow users to improve existing prompts.

## Features

### improve

```bash
prompt improve summarize.md
```

Read existing prompt.

Ask:

```text
What would you like to improve?
```

Examples:

- Too verbose
- Too short
- Too generic
- Wrong audience
- Produces too much code
- Produces too little code
- Other

Send prompt + improvement request to AI.

Generate improved prompt.

Display improved prompt.

Optionally save changes.

## Success Criteria

- Existing prompts can be improved
- Improvements feel relevant
- Workflow is faster than manually editing prompts

---

# Phase 3: Prompt Review

## Goal

Provide feedback on prompt quality.

## Features

### review

```bash
prompt review summarize.md
```

AI analyzes prompt.

Returns:

- Strengths
- Weaknesses
- Suggestions

Example:

```text
Strengths
- Clear goal
- Good audience definition

Weaknesses
- Missing constraints
- Output format unclear

Suggestions
- Add length requirement
- Specify markdown output
```

## Success Criteria

- Reviews are actionable
- Suggestions are specific
- Reviews help improve prompts

---

# Phase 4: Better UX

## Goal

Improve day-to-day usability.

## Features

### Interactive Menus

Instead of free text for everything:

```text
Select output format:

1. Markdown
2. JSON
3. Plain Text
4. Custom
```

### Prompt Preview

Show prompt before saving.

### Prompt Editing

Allow prompt editing before save.

### Clipboard Support

Copy generated prompt directly to clipboard.

## Success Criteria

- Faster workflow
- Less typing
- Better user experience

---

# Phase 5: Prompt Library

## Goal

Make prompts reusable.

## Features

### List Prompts

```bash
prompt list
```

### Open Prompt

```bash
prompt show summarize.md
```

### Search Prompts

```bash
prompt search article
```

### Organize Prompts

Store prompts in:

```text
~/.prompt/prompts/
```

## Success Criteria

- Prompts become reusable assets
- Easy to find old prompts
- Useful personal prompt collection
